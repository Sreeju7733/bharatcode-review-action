# Security Policy

This policy outlines supported versions and security disclosure procedures for BharatCode PR Reviewer.

---

## Supported Versions

Security updates and patches are actively maintained for the following versions:

| Version | Status |
| :--- | :--- |
| `v1.x` | Supported |
| `< v1.0.0` | Unsupported |

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately using GitHub's built-in private security advisory:

1. Navigate to the [Security Advisories tab](https://github.com/Sreeju7733/bharatcode-review-action/security/advisories) on this repository.
2. Click **Report a vulnerability**.
3. Provide details and steps to reproduce.

This ensures vulnerabilities are addressed privately before public release.
