# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The BharatCode team takes the security of our GitHub Actions, developer tools, and users very seriously.

If you believe you have discovered a vulnerability in `bharatcode-review-action`, please report it directly to:

📧 **security@bharatcode.ai**

Please include:
- A description of the vulnerability and affected versions or features.
- Steps to reproduce or a proof of concept.
- Any potential impact on GitHub repositories or workflows.

### Policy Guidelines
- We request a **90-day responsible disclosure window** to review, patch, and release a fix before public disclosure.
- We will acknowledge receipt of your vulnerability report within 48 business hours.
- We will provide regular updates on remediation progress.
